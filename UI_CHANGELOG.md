# UI Changelog — 2.1.0

## Нова візуальна система

- fantasy-RPG палітра із синьою сталлю, золотом, рунами та об’ємними рамками;
- новий оригінальний логотип `Math Hero — Легенди множення`;
- портрет обраного героя у HUD і великий preview на головному екрані;
- об’ємні кнопки з hover/press-станами замість універсальних плоских карток;
- головне меню у форматі ігрового стартового екрана з режимами, профілем та статистикою;
- карта восьми королівств із власними кольорами, прогресом і зірками;
- окрема маршрутна карта п’яти етапів кожного регіону;
- новий бойовий HUD, HP-рамка, комбо, щит, ульта, рунічний приклад і кнопки відповідей;
- окрема фіолетова стилістика битв із босами;
- тематичні екрани паузи, перемоги, поразки, результатів, магазину, статистики й налаштувань;
- браузерні `alert/confirm` замінені на власні ігрові модальні вікна;
- окремі responsive-композиції для desktop, tablet і mobile;
- підтримка high contrast та reduced motion збережена.

## Технічні зміни

- усі попередні DOM ID та ігрові callbacks збережені;
- додано UI assets у централізований manifest;
- додано автоматичні UI contract tests;
- 63/63 PNG-ресурси проходять валідацію;
- 22/22 тестів проходять;
- production build створюється без зовнішніх залежностей.
