# Math Hero: Side-Scroller RPG ⚔️

Браузерна 2D RPG для засвоєння **тільки таблиці множення**, українською та англійською. Навчальні завдання завжди мають формат `A × B = ?`; прикладів на додавання, віднімання, ділення та інші арифметичні дії немає.

## Реалізовано

- 8 регіонів і 40 окремих етапів кампанії — по 5 у кожному регіоні.
- Послідовне відкриття етапів, зірки, точність, рекорди часу та повторне проходження.
- Чотири навчальні рівні: 2, 3, 4 варіанти відповіді та ручне введення.
- Режими однієї таблиці, змішаного тренування, слабких місць, майстерності, нескінченного походу й таємного боса.
- Адаптивний генератор із повторенням помилок і статусами `NEW`, `FAMILIAR`, `UNSTABLE`, `MASTERED`, `NEEDS_REVISION`.
- Канонічна статистика: `3 × 7` і `7 × 3` належать до одного факту множення.
- Бойові комбо: критичний удар, щит, посилення та ультимативна атака.
- Боси з runtime-HP, трьома фазами, переходами та буферизацією правильної атаки під час фазової невразливості.
- Нескінченні хвилі з масштабуванням HP, елітними ворогами, босами та рекордами без необмеженого росту масиву ворогів.
- 4 архетипи героя, магазин косметики, еволюційні стадії, XP, рівні, монети й досягнення.
- 32 звичайні вороги, 8 елітних, 8 регіональних босів і секретний бос у централізованому бестіарії.
- 195 перевірених PNG-ресурсів у централізованому маніфесті, включно з логотипом та рунічною UI-текстурою.
- Рухома камера, паралакс, 8 фонів, час доби, погода та візуальні події рівнів.
- Повна пауза бойових таймерів, музики, введення та переходів фаз.
- Локальне збереження, міграція схеми, резервне копіювання, імпорт та експорт JSON.
- Повністю стилізований fantasy-RPG інтерфейс: гербовий логотип, портрет героя, об’ємний HUD, карта королівств, маршрут етапів, руни, босові рамки, ігрові кнопки, окремі екрани перемоги, поразки, паузи, магазину та налаштувань.
- Дві мови інтерфейсу — українська та англійська — з перемикачем у налаштуваннях; перший запуск бере мову браузера. Перекладено все, включно з назвами 113 істот, 8 регіонів, 46 досягнень і реплік у бою.
- Мобільний горизонтальний формат для екранів 5–7 дюймів: панель відповідей у два стовпці, масштаб персонажів за вільною смугою екрана, ворота орієнтації в портреті.
- Адаптивне компонування для ПК і мобільних екранів, клавіатура, сенсорне керування, високий контраст і зменшений рух.
- Автономні тести та збірка без сторонніх npm-залежностей.

## Запуск на Windows

1. Встановіть **Node.js 20 або новіший**.
2. Розпакуйте проєкт у будь-яку папку.
3. Запустіть `launcher.bat`.
4. Браузер відкриє локальну адресу автоматично. Якщо стандартний порт зайнятий, сервер підбере наступний вільний.

Жорсткої прив’язки до `F:\math` немає.

## Запуск із термінала

```bash
node scripts/serve.mjs --open
```

Або:

```bash
npm run dev
```

Інтернет та `npm install` для запуску не потрібні.

## Перевірка і production-збірка

```bash
npm run verify
```

Команда послідовно виконує:

1. валідацію 195 PNG-ресурсів;
2. перевірку синтаксису JavaScript;
3. 49 модульних та інтеграційних тестів, включно з перевірками UI-оболонки;
4. створення папки `dist`.

На Windows можна запустити `build.bat`.

## Керування

- Миша або сенсорний екран — кнопки відповіді й меню.
- Клавіші `1–4` — вибір варіанта.
- Цифри, `Backspace`, `Enter` — ручне введення.
- `Escape` — пауза.

## Структура

- `src/main.js` — життєвий цикл сесії та координація систем.
- `src/math/` — генерація й адаптивне повторення множення.
- `src/game/` — герой, бестіарій, нагороди та діалоги.
- `src/engine/` — renderer, sprites, частинки, босові фази й scheduler.
- `src/ui/` — меню та математична панель.
- `src/storage/` — схема й міграції збереження.
- `src/i18n/` — локалізація: `ui.js` (рядки інтерфейсу двома мовами), `content.js` (англійські накладки на назви істот, регіонів, досягнень і реплік), `index.js` (рантайм `t()` / `tc()`).
- `src/assets/assetManager.js` — єдине джерело шляхів до ресурсів.
- `scripts/` — локальний сервер, генерація, валідація й збірка.
- `tests/` — автоматичні тести.

## Поточне графічне обмеження

Наявні ресурси є валідними унікальними процедурними PNG, а рухи додатково стилізуються runtime-анімаціями. Повні багатокадрові професійні sprite sheets для кожного героя та монстра ще не створені. Архітектура маніфесту дозволяє замінювати ресурси без переписування бойової логіки.
